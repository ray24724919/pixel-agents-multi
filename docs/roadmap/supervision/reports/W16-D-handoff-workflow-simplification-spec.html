W16-D Handoff Workflow Simplification

Product spec summary for reducing Handoff / Handoff Queue / executor workflow complexity. Full report: W16-D-handoff-workflow-simplification-spec-report.md

Recommended Mental Model

Handoff

A safe local context note written under docs/agent-handoffs/.

Work Package

Executable instructions derived from a handoff for a downstream executor.

Executor

A visible Codex or Claude agent working on a package, with local evidence only.

Recommended Naming

  • Handoff Queue becomes Work Queue.
  • Recent Handoffs becomes Handoff Library.
  • Refresh completion becomes Refresh report status.
  • Open report becomes Open executor report.
  • Copy prompt becomes Copy work-package prompt.

Primary Flow

Draft handoff Work package ready Dispatched Active / waiting / blocked Report ready Reviewed / done

Visible Actions

Keep Prominent

  • Create work package
  • Launch Codex / Launch Claude
  • Refresh report status
  • Open executor report
  • Mark reviewed

Move To More

  • Open handoff / Open work package
  • Copy handoff or work-package prompt
  • Mark stale / Reset draft
  • Manual dispatch and execution status controls
  • Link agent

W17 Sequence

  • W17-A: Work Queue IA and naming.
  • W17-B: Row next-action compression.
  • W17-C: Executor state and review cue consolidation.
